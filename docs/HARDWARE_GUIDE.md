## 기본 개념

### 아두이노 우노 핀 종류

```
   ┌─────────────────────────────────┐
   │  디지털 핀 (D0 ~ D13) - 14개      │
   │  - PWM 가능: 3, 5, 6, 9, 10, 11   │
   │  - D0, D1: 시리얼 통신용 (사용 X)  │
   │                                 │
   │  아날로그 핀 (A0 ~ A5) - 6개       │
   │  - 0~1023 값을 읽음                │
   │  - A4, A5: I2C 통신용 (LCD 등)    │
   │                                 │
   │  전원                            │
   │  - 5V, 3.3V, GND, Vin           │
   └─────────────────────────────────┘
```

### 신호 종류

| 종류 | 설명 | 예시 |
|------|------|------|
| **아날로그 입력** | 0~1023 범위 값 읽기 | CDS, 사운드, 가변저항 |
| **디지털 입력** | HIGH/LOW만 읽기 | 버튼, 키패드 |
| **디지털 입출력 (특수)** | 데이터 통신 | DHT11, 초음파 |
| **I2C 통신** | A4(SDA), A5(SCL) 사용 | LCD |
| **PWM 출력** | 0~255로 강도 조절 | 부저, RGB LED |

## 핀 배치 종합표

**프로젝트 전체 사용 시 권장 핀 배치** (충돌 없도록 미리 설계함)

| 센서 / 출력 | 핀 | 핀 종류 | 비고 |
|------------|----|---------|----|
| CDS 조도 | A0 | 아날로그 입력 | 풀다운 저항 10kΩ 필요 |
| 사운드 센서 | A1 | 아날로그 입력 | 모듈에 저항 내장 |
| 가변저항 | A2 | 아날로그 입력 | 자체 저항 |
| LCD I2C SDA | A4 | I2C | LCD 전용 |
| LCD I2C SCL | A5 | I2C | LCD 전용 |
| DHT11 데이터 | D2 | 디지털 입출력 | 모듈에 저항 내장 |
| 초음파 TRIG | D3 | 디지털 출력 | |
| 초음파 ECHO | D4 | 디지털 입력 | |
| 부저 | D8 | 디지털 출력 | PWM 사용 시 D9로 변경 |
| 키패드 ROW1~4 | D9~D12 | 디지털 입출력 | |
| 키패드 COL1~4 | D5~D7, D13 | 디지털 입출력 | |
| 내장 LED | D13 | 디지털 출력 | 키패드와 충돌 시 LED 제거 |

> 핀이 부족하면 키패드를 가장 마지막에 추가하세요. 핀 8개를 잡아먹습니다.

## 전원 분배

빵판의 좌우 양쪽 빨간/파란 줄(전원 레일)을 활용합니다.

```
빵판 상단:
  +레일 (빨강) ←─── 5V ←──── 아두이노 5V 핀
  -레일 (파랑) ←─── GND ←─── 아두이노 GND 핀

각 센서는 빵판의 +레일과 -레일에서 전원을 끌어다 씀.
신호선만 아두이노 디지털/아날로그 핀에 연결.
```

**중요**: 모든 센서의 GND는 반드시 아두이노 GND와 **공통 접지**되어야 합니다. 빵판 -레일 하나로 묶으면 됩니다.

## 센서별 배선법

### 1. CDS 조도 센서

빛의 양에 따라 저항값이 변하는 센서. 아두이노에서 직접 저항만 측정할 수 없으므로 **분압 회로**를 만들어야 합니다.

**부품**
- CDS 셀 1개
- 10kΩ 저항 1개

**배선**

```
      5V ─── CDS 셀 ───┬─── A0 (아두이노)
                        │
                       10kΩ 저항
                        │
                       GND
```

빵판 배선 그림:

```
  +레일(5V) ─── [CDS 다리1]
                [CDS 다리2] ──┬── A0
                              │
                            [10kΩ]
                              │
                          -레일(GND)
```

**아두이노 코드**

```cpp
int cdsValue = analogRead(A0);   // 0(어두움) ~ 1023(밝음)
```

**테스트**: 손으로 CDS를 가리면 값이 낮아지고, 손전등을 비추면 높아져야 함.

### 2. DHT11 온습도 센서 (모듈형)

3핀 모듈형은 저항이 내장되어 있어 배선이 단순합니다.

**부품**: DHT11 모듈 1개

**핀 배치**: 모듈에 표시되어 있음
- `S` 또는 `DATA` → 데이터 핀
- `+` 또는 `VCC` → 5V
- `-` 또는 `GND` → GND

**배선**

```
  DHT11 모듈
  ┌─────────┐
  │  S  + - │
  └──┬──┬─┬─┘
     │  │ │
     │  │ └─── GND
     │  └───── 5V
     └──────── D2 (아두이노)
```

**필수 라이브러리**: Arduino IDE → Tools → Manage Libraries → `DHT sensor library` (Adafruit) 검색 후 설치

**아두이노 코드**

```cpp
#include <DHT.h>
#define DHTPIN 2
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  dht.begin();
}

void loop() {
  float temp = dht.readTemperature();   // 섭씨
  float humid = dht.readHumidity();     // %
}
```

**주의**: DHT11은 읽기 주기가 느립니다. 최소 **2초 간격**으로 읽어야 정확한 값이 나옵니다.

### 3. HC-SR04 초음파 센서

거리 측정용. TRIG로 신호 발사, ECHO로 반사 시간 측정.

**부품**: HC-SR04 모듈 1개 (4핀: VCC, TRIG, ECHO, GND)

**배선**

```
  HC-SR04
  ┌─────────────────┐
  │ VCC TRIG ECHO GND│
  └─┬───┬────┬────┬─┘
    │   │    │    │
    │   │    │    └─── GND
    │   │    └─────── D4 (아두이노)
    │   └──────────── D3 (아두이노)
    └──────────────── 5V
```

**아두이노 코드**

```cpp
#define TRIG_PIN 3
#define ECHO_PIN 4

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
}

long readDistance() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  
  long duration = pulseIn(ECHO_PIN, HIGH, 30000);  // timeout 30ms
  long distance = duration * 0.034 / 2;            // cm 변환
  return distance;
}
```

**주의**: 측정 범위는 약 **2cm ~ 400cm**. 너무 가까우면 0이나 이상한 값 나옴.

### 4. 사운드 센서

소리(진동)를 감지하는 센서. 보통 4핀 모듈형 (VCC, GND, DO, AO).

**부품**: 사운드 센서 모듈 1개

**배선** (아날로그 출력 사용 시)

```
  사운드 센서 모듈
  ┌──────────────────┐
  │ VCC GND DO  AO   │
  └─┬────┬───┬───┬───┘
    │    │   │   │
    │    │   │   └─── A1 (아두이노) - 소리 강도값
    │    │   └─────── (사용 안 함, 디지털 임계 출력)
    │    └─────────── GND
    └──────────────── 5V
```

**아두이노 코드**

```cpp
int soundLevel = analogRead(A1);   // 0~1023
```

**캘리브레이션**: 모듈에 파란 가변저항(potentiometer)이 있음. 작은 드라이버로 돌려서 감도 조절. 조용할 때 값이 낮게(예: 50 이하), 박수치면 높게(예: 800 이상) 나오도록 조정.

### 5. 가변저항 (포텐셔미터)

손잡이를 돌려서 저항을 변경하는 부품. 무전기 다이얼 역할.

**부품**: 10kΩ 가변저항 1개 (3핀)

**배선**

```
  가변저항 (위에서 본 모습)
  ┌──┐
  │○│  ← 손잡이 돌리는 부분
  └┬┘
   │ 다리 1 (양쪽 끝) ──── 5V
   │ 다리 2 (가운데)  ──── A2 (아두이노)
   │ 다리 3 (양쪽 끝) ──── GND
```

**다리 1과 3은 바꿔도 됨** (회전 방향만 반대가 됨).

**아두이노 코드**

```cpp
int potValue = analogRead(A2);   // 0 (한쪽 끝) ~ 1023 (반대쪽 끝)
```

**테스트**: 손잡이를 돌리면 0 ↔ 1023 사이로 부드럽게 변해야 정상.

### 6. 4x4 키패드

16개 버튼이 4행 4열로 배치된 멤브레인 키패드. **핀 8개를 사용**하므로 가장 마지막에 추가.

**부품**: 4x4 멤브레인 키패드 1개 (8핀 케이블 1줄)

**핀 배치**: 케이블의 왼쪽부터 순서대로
- 1번 핀: ROW1
- 2번 핀: ROW2
- 3번 핀: ROW3
- 4번 핀: ROW4
- 5번 핀: COL1
- 6번 핀: COL2
- 7번 핀: COL3
- 8번 핀: COL4

**배선**

```
  ROW1 ──── D9
  ROW2 ──── D10
  ROW3 ──── D11
  ROW4 ──── D12
  COL1 ──── D5
  COL2 ──── D6
  COL3 ──── D7
  COL4 ──── D13
```

> D13은 내장 LED와 공유. 키패드 사용 시 내장 LED 점등은 디버깅에 영향 줄 수 있음.

**필수 라이브러리**: Arduino IDE → Manage Libraries → `Keypad` (Mark Stanley, Alexander Brevig) 설치

**아두이노 코드**

```cpp
#include <Keypad.h>

const byte ROWS = 4;
const byte COLS = 4;

char keys[ROWS][COLS] = {
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}
};

byte rowPins[ROWS] = {9, 10, 11, 12};
byte colPins[COLS] = {5, 6, 7, 13};

Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);

void loop() {
  char key = keypad.getKey();
  if (key) {
    Serial.println(key);
  }
}
```

### 7. LCD I2C

I2C 통신을 사용하는 16x2 LCD 모듈. 4선만 연결하면 됨.

**부품**: I2C 백팩이 달린 16x2 LCD 1개 (뒷면에 작은 보드가 붙어있음)

**배선**

```
  LCD I2C 모듈 (뒷면)
  ┌──────────────────┐
  │ GND VCC SDA SCL  │
  └─┬────┬────┬───┬──┘
    │    │    │   │
    │    │    │   └─── A5 (아두이노)
    │    │    └─────── A4 (아두이노)
    │    └──────────── 5V
    └───────────────── GND
```

**필수 라이브러리**: Arduino IDE → Manage Libraries → `LiquidCrystal I2C` (Frank de Brabander) 설치

**I2C 주소 확인**: 보통 `0x27` 또는 `0x3F`. 아래 코드로 확인 가능 (I2C Scanner 검색).

**아두이노 코드**

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);   // 주소가 다르면 0x3F로 변경

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Hello");
}
```

### 8. 부저 + LED (출력)

#### 능동 부저 (5V active buzzer)

핀에 HIGH만 주면 소리가 남.

```
  부저 (+) ───── D8 (아두이노)
  부저 (-) ───── GND
```

```cpp
digitalWrite(8, HIGH);   // 소리 ON
delay(200);
digitalWrite(8, LOW);    // 소리 OFF
```

#### 수동 부저 (passive buzzer)

PWM 신호를 줘야 음정이 나옴.

```cpp
tone(8, 1000);    // 1000Hz 톤
delay(200);
noTone(8);
```

#### 일반 LED

**저항 220Ω 필수**. 안 그러면 LED 타버림.

```
  D8 ──── [220Ω 저항] ──── LED(+) ──── LED(-) ──── GND
                          (긴 다리)    (짧은 다리)
```

```cpp
digitalWrite(8, HIGH);   // 켜짐
```

#### RGB LED (4핀)

가장 긴 다리가 **공통 핀** (보통 -, GND).

```
  R 다리 ── [220Ω] ── D9
  공통 다리 ─────── GND
  G 다리 ── [220Ω] ── D10
  B 다리 ── [220Ω] ── D11
```

```cpp
analogWrite(9, 255);    // 빨강 최대
analogWrite(10, 0);
analogWrite(11, 0);
```

## 빵판 사용법

### 빵판 구조

```
        ┌─ 전원 레일 (가로 한 줄로 연결됨) ─┐
  + + + + + + + + + + + + + + + + + + + + + +   ← 빨강 (+)
  - - - - - - - - - - - - - - - - - - - - - -   ← 파랑 (-)
  
  a │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │   ← 세로 5개 구멍이 한 묶음
  b │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │   ← (a~e가 한 그룹)
  c │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │
  d │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │
  e │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │
  ─────────────────  (중앙 홈)  ─────────────
  f │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │   ← f~j가 다른 그룹
  g │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │
  h │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │
  i │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │
  j │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │
  
  - - - - - - - - - - - - - - - - - - - - - -   ← 파랑 (-)
  + + + + + + + + + + + + + + + + + + + + + +   ← 빨강 (+)
```

### 사용 규칙

1. **전원 레일은 가로로 한 줄로 연결됨** → 어디든 5V 꽂으면 그 줄 전체가 5V
2. **세로 그룹은 a~e, f~j가 따로** → a1과 a5는 따로지만, a1과 e1은 연결됨
3. **중앙 홈은 끊어져 있음** → e와 f는 별개. IC 칩을 꽂기 위한 구조

### 권장 작업 순서

1. 아두이노 5V → 빵판 +레일에 연결 (점퍼선 빨간색)
2. 아두이노 GND → 빵판 -레일에 연결 (점퍼선 검정색)
3. 센서를 빵판에 꽂음
4. 센서의 VCC → +레일, GND → -레일 (모두 빵판 내에서 처리)
5. 신호선만 아두이노 디지털/아날로그 핀에 연결

## 트러블슈팅

### 센서값이 0만 나오거나 1023만 나옴

- GND 연결 확인 (가장 흔한 원인)
- 센서가 5V를 받고 있는지 확인 (멀티미터로 체크)
- 분압 저항 빠진 경우 (CDS, 일반 LDR)

### 값이 들쭉날쭉함 (노이즈)

- 빵판 접촉 불량 → 다른 구멍으로 옮겨봄
- 점퍼선 단선 → 다른 선으로 교체
- 코드에서 `delay(50)` 또는 평균값 처리 추가

### DHT11이 NaN 반환

- 라이브러리 미설치
- 데이터 핀 잘못 연결
- 읽기 주기가 너무 빠름 (최소 2초 간격 필요)
- VCC가 3.3V로 들어감 (5V 필요)

### 키패드 입력이 이상하게 잡힘

- ROW와 COL 핀 순서가 뒤바뀜 → 케이블 끝에서부터 확인
- 라이브러리 설치 확인 (`Keypad`)
- 8개 핀 모두 단단히 꽂혔는지

### 아두이노가 갑자기 꺼지거나 재부팅

- 전류 부족 → USB 외에 추가 전원 필요할 수 있음
- 너무 많은 LED를 한 번에 켰을 때 발생 가능
- 합선 의심 → 모든 연결 다시 확인

### 시리얼 모니터에 깨진 글자

- 보드레이트 불일치
  - `Serial.begin(9600)` ↔ 시리얼 모니터 우측 하단 "9600 baud" 일치 확인
