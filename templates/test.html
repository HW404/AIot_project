실행 방법

  1. 아두이노에 sensor_check.ino 업로드 + USB로 라파에 연결
  2. 노트북: $env:INPUT_MODE="tcp"; python main.py
  3. 라파: cd raspberry && python3 main.py
  4. 이 페이지 새로고침
  5. WebSocket: 연결됨 ✓ / 라파 연결됨 ✓ / 6개 센서 카드 모두 초록색이면 성공

문제 해결

  • WebSocket 연결 안 됨 → 노트북 서버 실행 확인
  • 라파 미연결 → 라파의 config.py에서 SERVER_HOST 확인, 노트북 방화벽 9000 포트 허용
  • 특정 센서만 회색 → 그 센서 배선 확인 (아두이노 시리얼 모니터에서 출력 확인)
  • 이상한 값 → 아두이노 코드의 baud rate가 9600인지 확인
