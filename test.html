테스트 방법

  1. 아두이노에 connection_test.ino 업로드
  2. USB 케이블로 노트북에 연결
  3. Python 서버 실행: python main.py
  4. 이 페이지 새로고침
  5. 아두이노 LED가 1초마다 깜빡이고, 위 로그에 HELLO 1, 2, 3... 메시지가 들어오면 성공

문제 해결

  • WebSocket 연결 안 됨 → Python 서버가 실행 중인지 확인
  • 시리얼 포트 못 찾음 → 아두이노 IDE 종료 후 재시도 (포트 점유 충돌)
  • 이상한 문자만 들어옴 → 보드레이트 불일치. 아두이노 코드의 Serial.begin(9600)과 일치하는지 확인
